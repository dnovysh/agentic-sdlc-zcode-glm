# Agentic SDLC в ZCode и GLM 5.x

[Читать онлайн](https://dnovysh.github.io/agentic-sdlc-zcode-glm/) · [Открыть PDF](agentic-sdlc-zcode-glm.pdf) · [Релизы](https://github.com/dnovysh/agentic-sdlc-zcode-glm/releases) · [Промпты одним файлом](prompts.md)

Адаптация книги Тёмы Пулявина [«Как построить Agentic SDLC в своём репозитории»](https://github.com/pulyavin/agentic-sdlc) для ZCode 4.0 и моделей GLM 5.x.

В оригинале всё написано для Claude Code. Здесь тот же путь: подготовить репозиторий так, чтобы агент работал по правилам команды и сам проверял свою работу. Примеры перенесены с GitHub на GitLab, для команд добавлены варианты для PowerShell, про Windows есть отдельное приложение.

## Что внутри

Одиннадцать глав и три приложения. По порядку: почему агент без подготовки пишет слоп, выбор модели и уровня рассуждений, MCP, `AGENTS.md`, скиллы и команды, запуск проекта и браузер, тесты, линтеры и хуки, CI, ревью, безопасность. Последняя глава о том, как теперь выглядит разработка от запроса до прода.

В приложениях собрана адаптация для Windows и PowerShell со шпаргалкой соответствий команд, справочник по конфигурации ZCode 4.0 и указатель промптов.

Каждая глава заканчивается разделом «С чего начать сегодня» и проверкой. Промпты лежат в тексте книги и отдельным списком в [prompts.md](prompts.md), всего их 49. Рисунков нет, только текст.

## Чем отличается от оригинала

- Всё, что относится к Claude Code, переписано под ZCode: где лежат скиллы, субагенты и хуки, как устроены хуки, какие бывают режимы выполнения.
- Команды даны для Bash и PowerShell.
- Вместо GitHub в примерах GitLab.
- Сведения о ZCode, GLM 5.x и тарифах сверены с официальной документацией Z.ai по состоянию на ноябрь 2026 года.
