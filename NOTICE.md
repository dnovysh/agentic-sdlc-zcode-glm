## Что взято из исходной книги

- Структура книги: порядок глав и разделов.
- Названия большинства глав и ряда разделов.
- Часть промптов и примеров. В исходной книге они переданы в общественное достояние на условиях CC0 1.0.
- Отдельные формулировки, примеры и сравнительные таблицы из текста.

## Что изменено

- Текст переработан и дополнен для ZCode 4.0 и моделей GLM 5.x. Сведения о продуктах сверены с их официальной документацией.
- Примеры ориентированы на GitLab. Команды даны в двух вариантах: для Bash и для PowerShell.
- Добавлены приложения: «Windows и PowerShell», «Справочник по конфигурации ZCode 4.0», «Указатель промптов».
- Иллюстраций нет: книга содержит только текст.
- Примеры из исходной книги, рассчитанные на Claude Code, заменены примерами для ZCode.
